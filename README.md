# KNN and Decision Tree Examples

This repository contains simple, beginner-friendly Python examples of two popular machine learning algorithms:

1. K-Nearest Neighbors (KNN) 
   - Implemented using `scikit-learn`.  
   - Predicts the label of a new point based on the labels of its nearest neighbors.  
   - Includes a scatter plot visualization showing training points and the new point.

2. Decision Tree Classifier 
   - Implemented using `scikit-learn`.  
   - Builds a tree by asking simple “questions” about features to split data into pure groups.  
   - Predicts the label of a new point following the decision rules learned from the data.

---

Example Output
KNN: Prediction for point [3, 2] → blue
Decision Tree: Prediction for point [3, 2] → blue

Visualization
KNN script includes a scatter plot showing:
Red and blue points (training data)
Black X marker (new point to predict)

Decision Tree can also be visualized using libraries like graphviz (optional).
